## 1. ページの目的とコンセプト

**コンセプト：凛と整い、私らしく。**

健康・美容・姿勢を支えるサロンであることと、ミセス・インターナショナル2027公式パートナーとして女性の挑戦を支える姿勢を、一続きのブランドストーリーにします。

読後の行動は、HOT PEPPER Beautyで詳細を確認し予約することを中心にします。メニュー名の一覧、料金、クーポン、施術時間別の商品カードは掲載しません。

構成は「表紙 → 公式パートナー → 健康・美容・姿勢への考え方 → 空間 → 予約 → アクセス → SNS」。料金表や三列の特徴カードを起点にせず、写真の大きさ・余白・文章の配置に強弱をつけます。

## 2. ビジュアルの設計

### 色

- アイボリー `#F7F3EA`：主背景。提供ロゴの背景に近い穏やかな色。
- ディープネイビー `#17283B`：予約導線、章の切り替え、主要文字。
- ブロンズゴールド `#947337`：細線や装飾。小さな本文文字には使わない。
- ウォームグレー `#E8E1D7`：写真まわりの余白。
- ダスティローズ `#BE8F91`：大会用ロゴとのつながりをつくる少量の差し色。

色はロゴ・提供チラシから着想した候補値です。制作時に実画像とのなじみと文字コントラストを確認します。

### 文字と余白

日本語の大見出しは読みやすい明朝体、本文・アクセス・ボタンはゴシック体。装飾的な英語は補助に留め、日本語だけで内容と操作が分かる構成にします。本文はスマートフォンで16px程度を基本とし、行間を十分に取ります。

PCでは写真が画面幅の大半を使う場所と、文章を細く集める場所を交互に配置。スマートフォンでは文章と写真の順序を設計し直し、単純なPC縮小版にしません。

主なモチーフは、ロゴの円と身体の自然な曲線を思わせる細い弧。章の境目など数か所だけに使い、王冠・金箔・きらめきを繰り返す装飾にはしません。

## 3. ページ構成

### 01｜ヒーロー：短い言葉と、一枚の大きな写真

**コピー案：凛と、私らしく。**

ヘッダーを除く最初の画面を一枚のビジュアルで構成します。人物は中央付近に置き、コピーを画像下部中央の余白へ重ねます。左右二分割は使用しません。

- PCヘッダー：中央に通常ロゴ、片側にページ内ナビ、もう片側に予約リンク。
- SPヘッダー：通常ロゴと読み取れる店舗名、メニューボタン。
- ヒーローの要素：短いコピー、店舗名、控えめなスクロール表示。長い説明文は置かない。
- 予約はヘッダー・SP下部固定バーからいつでも利用可能。
- `100svh`を基準に、ヘッダー・下部固定バー・セーフエリアを含めた最初の画面を設計。

生成するヒーローは、アイボリーの布、柔らかな自然光、自然な立ち姿の成人女性を主題にします。髪はまとめ、肩から背中への線と自然な姿勢が伝わる構図。実店舗を再現した背景や、施術効果の比較画像は作りません。

PC用横長とSP用縦長を別に用意し、中心人物とコピー用余白が各画面で成立するよう調整します。生成画像はブランドの雰囲気を表す写真として扱い、店内紹介は提供の店舗写真を用います。

### 02｜公式パートナー：このサロンならではのメッセージ

ヒーロー直後に、ミセス・インターナショナル2027公式パートナーとしての紹介を配置します。

`logo02.jpg`を中央に十分な大きさで掲載し、その下に本文を組む縦方向の構成。ロゴ内の文字を残したまま表示し、全体を切り抜いたり変形したりしません。SPでは画像内文字の読みやすさを確認し、重要な内容はHTML本文でも読めるようにします。

掲載文章案（ご希望テキストの表記と改行を整理）：

> 高輪鍼灸 AC Wellnessは、
> 「ミセス・インターナショナル 2027」公式パートナーに就任。
> 社会貢献に挑む女性たちを支え、共に輝く未来を創ります。
> 心と身体を整え、あなた史上最高の自分へ―。

併せて「出場者の健康・美容・姿勢をサポートするサロン」であることを明記します。ヒーローに詰め込まず、余白とロゴを使って読ませる独立した章にします。

大会募集チラシはページ全体の背景やヒーローには使用しません。募集情報への遷移が主目的にならないよう、サロンの紹介と予約を中心に設計します。

### 03｜健康・美容・姿勢：サロンの考え方

見出し案：**美しさを支える、健やかな土台。**

「健康」「美容」「姿勢」を大きな文字で、段差のある位置に配置します。横並びの三枚カードにはせず、一つの紙面に連続した考え方として表現します。

説明は三つ合わせて短い段落二〜三本程度。日々のコンディション、自分らしい美しさ、立ち姿に向き合うことを伝えます。具体的な施術メニュー、料金、改善率、確約する効果は掲載しません。

下側に、手元や肩まわりの提供施術イメージを横長で配置。画像を文章と少し重ね、次の空間紹介へつなげます。

章の末尾に「詳しくはこちらへ」と、遷移先が分かる「HOT PEPPER Beautyで詳細・ご予約」の補助表示を置きます。

### 04｜サロンの空間：初めての来店を具体的に

見出し案：**高輪で、自分に向き合うひととき。**

施術室写真を大きく、建物外観写真を小さめに、上下に位置をずらして配置します。写真の横に長文を置く構成は繰り返さず、短いキャプションと余白で見せます。

掲載内容は、2席のサロンであること、BRIDARIUM MUE高輪本店の地下1階にあること。提供チラシ内の豪華な室内イメージを実際の施術室として使用しません。

人物紹介を追加する場合は、提供資料に含まれる人物の氏名・肩書きと、鮮明な掲載用写真の有無を確かめてから構成します。現計画にスタッフプロフィールや実績数は追加しません。

### 05｜詳細・ご予約：迷わず外部予約へ

ネイビーの幅広い予約エリアを設け、短い一文と主ボタンを中央に配置。ロゴ・料金表・SNSリンクを一度に並べず、予約の行動が明確になる面にします。

- 主ボタン：**詳しくはこちらへ ↗**
- 補助表示：**HOT PEPPER Beautyで詳細・ご予約**
- 補助導線：LINE公式、電話。

予約ページの空き状況をLP内に表示したり、独自の予約フォームを設置したりはしません。LPから直接、指定のサロンページへ遷移します。

### 06｜アクセス：地下1階まで迷わない情報

最初に「高輪台駅 A2出口から徒歩3分」と建物名・地下1階を表示します。住所、営業時間、定休日、電話は常に読める状態にします。

電車、バス、車・駐車場の情報を区分。PCは写真と情報表、SPは縦に読み進める構成。SPで追加の交通手段を折りたたむ場合も、駅からの主要アクセスと住所を隠しません。

地図は指定Google Mapsへの目立つリンクを基本とします。埋め込み地図を追加する場合は、正しい建物位置と埋め込み先を確認し、遅延読み込みを行います。

### 07｜フッター：公式情報への入口

通常ロゴ、店舗名、Instagram、LINE公式、Google掲載ページを整列。SNSはアイコンだけにせず名称を併記します。Google掲載ページとGoogle Mapsの経路リンクは用途が分かる名前で区別します。

大会用ロゴは公式パートナーの章で使用し、通常ロゴの代わりに全ページへ反復しません。

## 5. GSAP / Lenisの計画

| 場所 | PCでの動き | SPでの動き |
| --- | --- | --- |
| ヒーロー | 写真を約1.04倍から等倍へ落ち着かせる約1.2秒の一度きりの演出。コピーは短く現れる | 同じ構図を縦長で再設計。動きは縮小、パララックスは使用しない |
| 公式パートナー | ロゴと本文を約0.15秒ずらして表示。区切りの細線を伸ばす | 通常の縦スクロールに合わせた短い表示 |
| 健康・美容・姿勢 | 画面の約0.7倍のスクロール区間だけ見出しを固定し、写真のマスクを開く。三つの言葉の強調を順に移す | 固定とスクロール連動を解除。三語と本文を最初から読める順に配置 |
| 空間紹介 | 写真を浅いマスクで出し、上下の写真にわずかな移動差をつける | マスク表示のみ、移動差は解除 |
| 予約リンク | hover/focus時に下線と矢印を短く動かす | 押下の反応を明確にする |
| 全体 | Lenisでホイール操作に軽い慣性を与える | タッチスクロールは標準操作を維持 |

GSAPは表示・マスク・スクロール連動に、LenisはPCのスクロール感の調整に役割を分けます。GSAPのtickerとLenisの更新を同期し、独立した更新ループを二重に回しません。

本文や予約リンクは長いロード演出で待たせず、JavaScriptが動かないときも内容とリンクを利用可能にします。`prefers-reduced-motion`ではスクロール補間、固定、移動アニメーションを解除します。

参照：

- https://gsap.com/docs/v3/Plugins/ScrollTrigger/
- https://github.com/darkroomengineering/lenis#gsap-scrolltrigger

- 固定バーはセーフエリアと同じ高さの下余白を確保し、本文・フッター・写真キャプションを覆わないようにする。

- 主予約、LINE、電話、SNSは見た目の優先度を分ける。

## 8. 実装と制作の順序

現在はAstroの初期ページ。`package.json`にはAstro、GSAP、Lenisが既に記載されています。

1. この計画に沿って、ヒーローの横長・縦長画像を生成し選定。
2. 店舗情報と外部リンクを`src/data/salon.ts`へ集約。
3. Astroのセクション別コンポーネントとして、PC・SPの静的レイアウトを実装。
4. 写真の切り取り、ロゴサイズ、コピーの改行、予約ボタンの優先順位を調整。
5. GSAP / Lenisの動きを実装し、SPと動きを抑える設定では簡略化。
6. 店名・住所・電話・営業時間、画像の代替テキスト、ページタイトル・説明・OGPを整備。本番URLは確定値を使い、canonical等に仮URLを入れない。
7. ビルドとPC・SPの表示、外部予約・LINE・電話・地図リンク、固定バーとの重なり、動きを抑える設定を確認。

開発サーバーが必要な段階では、プロジェクトの指示に従って`astro dev --background`を使用します。

Astroの関連ガイドは実装前に参照します。

- https://docs.astro.build/en/basics/astro-components/
- https://docs.astro.build/en/guides/styling/
- https://docs.astro.build/en/guides/routing/
